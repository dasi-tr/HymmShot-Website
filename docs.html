Capture, review, edit and export.

A step-by-step guide for HymmShot 1.0.0 on Windows.

Install HymmShot 1.0.0

  1. Download HymmShot 1.0.0
  2. Open HymmShot-Setup-1.0.0.exe from your Downloads folder and follow the installer.
  3. If Windows SmartScreen appears, confirm the file came from the official link above, choose More info, then Run anyway. The installer is not currently digitally signed.

Make a scrolling capture

  1. Open the browser, IDE, Terminal, CMD, log, chat or other Windows application you want to capture.
  2. Start a scrolling capture in HymmShot.
  3. Drag to select only the scrollable content area.
  4. Scroll normally through all the content you need.
  5. Press Enter or choose Finish. HymmShot combines the content into one continuous image.

Review capture issues

  1. After a long capture, open Capture Issue Review if HymmShot surfaces an area that may need attention.
  2. Jump directly to the relevant area.
  3. Use Previous and Next to move between issues.
  4. Choose recapture for the problematic area and capture that section again. You do not need to restart the full long capture.

Open an existing PNG

Choose the option to open an image, select a PNG, and open it in HymmShot. The image does not need to have been captured with HymmShot; the same editing and export tools are available.

Edit screenshots

  • Crop: trim the image to the exact area you want.
  • Pixelation / redaction: hide passwords, names, IDs, email addresses, private text or confidential values before sharing.
  • Highlight: add a transparent highlight without hiding the content.
  • Drawing: mark the image freehand.
  • Arrows and shapes: add arrows, rectangles, circles, check marks and X markers.
  • Text: add labels, notes and explanations.

Save or export

Save the finished image as an image file, or export a long screenshot as one continuous single-page PDF.

Windows security notice

HymmShot 1.0.0 is not digitally signed. Windows may show SmartScreen during installation or first launch. Download only from the official release link and see the security page for details.
